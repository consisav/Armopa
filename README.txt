# ARMOPA — Administración Inmobiliaria

Sitio web estático, responsive y editable para ARMOPA.

## Archivos
- `index.html` — página principal.
- `styles.css` — diseño y responsive.
- `script.js` — menú, idioma ES/EN, modal de clientes y formulario demo.
- `assets/` — logo oficial seleccionado y fotografías locales.

## Abrir
Haz doble clic en `index.html` para visualizar el sitio en el navegador.

## Editar en Visual Studio Code
Abre la carpeta `ARMOPA_Web` en Visual Studio Code y modifica `index.html`, `styles.css` o `script.js`.

## Nota
Los formularios y el Área de Clientes funcionan como demostración visual. Para producción deben conectarse a una base de datos/autenticación y a un servicio de envío de formularios.
