COMO USAR LOS 3 ARCHIVOS DEL SITIO (index.html, script.js, styles.css):
1. Copialos dentro de D:\PAGINAS WEB\Armopa\Armopa-repo, reemplazando los existentes.
2. NO borres assets/ ni supabase-config.js.
3. En VS Code, confirma con git status que aparecen como "modified".
4. Sube los cambios:
   git pull   (si pide "fetch first" antes del push)
   git add .
   git commit -m "Actualizacion completa del sitio"
   git push

COMO USAR LOS ARCHIVOS .sql:
Copia y pega el contenido de cada uno, EN ESTE ORDEN, en el SQL Editor de Supabase:
1. precalificacion.sql              -> crea las tablas base
2. migracion_persona_juridica.sql   -> agrega soporte para Persona Juridica (Empresa)
3. migracion_escolaridad.sql        -> agrega escolaridad y profesion

Recuerda tambien:
- Crear el bucket de Storage llamado "expedientes" en Supabase, marcado como PRIVADO
  (a diferencia del bucket "propiedades", que es publico).
- Configurar las politicas de RLS (Row Level Security) de las tablas
  expedientes_precalificacion y documentos_expediente, y del bucket "expedientes",
  para permitir INSERT/UPDATE/SELECT/DELETE al rol anon (publico).
