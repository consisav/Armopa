COMO USAR LOS 3 ARCHIVOS DEL SITIO (index.html, script.js, styles.css):
1. Copialos dentro de D:\PAGINAS WEB\Armopa\Armopa-repo, reemplazando los existentes.
2. NO borres assets/ ni supabase-config.js.
3. En VS Code, confirma con git status que aparecen como "modified".
4. Sube los cambios:
   git pull   (si pide "fetch first" antes del push)
   git add .
   git commit -m "Actualizacion completa del sitio"
   git push

COMO USAR precalificacion.sql:
Copia y pega su contenido completo en el SQL Editor de Supabase y ejecutalo.
Crea las tablas expedientes_precalificacion y documentos_expediente, ya corregidas
para PostgreSQL (no para MySQL). Recuerda configurar las politicas de RLS
(Row Level Security) para esas tablas antes de insertar datos desde el sitio publico.
