COMO USAR LOS 3 ARCHIVOS DEL SITIO (index.html, script.js, styles.css):
1. Copialos dentro de D:\PAGINAS WEB\Armopa\Armopa-repo, reemplazando los existentes.
2. NO borres assets/ ni supabase-config.js.
3. En VS Code, confirma con git status que aparecen como "modified".
4. Sube los cambios:
   git pull   (si pide "fetch first" antes del push)
   git add .
   git commit -m "Actualizacion completa del sitio"
   git push

COMO USAR LOS ARCHIVOS .sql:
Copia y pega el contenido de cada uno, EN EL ORDEN NUMERADO (1, 2, 3... 9), en
el SQL Editor de Supabase. Si algun archivo ya lo habias corrido antes, Supabase
puede marcar "already exists" en tablas/columnas ya creadas — es normal, solo
pasa al siguiente.

Recuerda tambien configurar en Supabase (fuera de estos scripts SQL):
- Bucket de Storage "expedientes" (PRIVADO) — documentos de precalificacion bancaria
- Bucket de Storage "cotizaciones" (PRIVADO) — PDFs de cotizacion adjuntos
- Politicas de RLS (Row Level Security) para el rol anon en las tablas:
  expedientes_precalificacion, documentos_expediente, propiedades,
  solicitudes_servicio, cotizaciones — y en ambos buckets de Storage.
